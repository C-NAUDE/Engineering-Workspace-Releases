# Engineering Workspace v0.1.3 Beta

This maintenance release improves update delivery. The **Install update** button in the app downloads the official installer, checks its SHA-256 checksum, and starts installation after the app closes. Fresh installs check for newer stable versions automatically; this can be disabled in the **?** menu. Previous installations may need **? → Check for updates now** if automatic checks were not enabled.

The symbolic engine and the v0.1.2 benchmark results are unchanged. Engineering Workspace remains free to use, closed source, and offline for calculations.

See [CHANGELOG.md](CHANGELOG.md) for earlier versions.
